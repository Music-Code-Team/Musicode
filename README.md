# Reglas de colaboración
1. Crear un virtual enviroment: **python -m venv venv**
2. Activar venv: **.\venv\Scripts\activate** en Windows
3. instalar dependencias: **pip install -r requirements.txt**
4. (En caso de añadir librerías, usar **pipreqs --encoding utf-8 --force .**)

# Crear ejecutbale
1. Ejecutar **auto-py-to-exe** ó **python -m auto_py_to_exe** en terminal
2. Seleccionar **Settings**



# Ejecutar CLI (python)
1. En terminal escribir **py Orquest.py tu/ruta/de/archivo**

# Ejecutar CLI (EXE)
1. En terminal escribir **Orquest tu/ruta/de/archivo**
